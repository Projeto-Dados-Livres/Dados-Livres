O Dados Livres agradece a sua vontade e disposição ao querer contribuir com uma plataforma livre e voluntária!


O principal propósito do projeto é ser um ambiente de colaboração e compartilhamento de fontes e aplicações que usam os dados abertos. Saiba mais conferindo a página sobre da plataforma.


Algumas considerações importantes:

  • O Dados Livres é um projeto totalmente voluntário, sem fins lucrativos e cultiva a filosofia software livre.

  • Todas as contribuições ao projeto são bem-vindas, afinal a ideia do Dados Livres é progredir por iniciativas voluntárias.

  • Por ser um projeto com poucas pessoas a frente e desenvolvido nos tempos livres, pode ser que demore para a sua contribuição ser vista, mas com calma te mandamos uma resposta.

Você pode contribuir com qualquer melhoria no projeto, como corrigir textos e links na plataforma, sugerir novas ideias, funcionalidades e muito mais. Em caso de dúvidas você pode nos contatar por e-mail na página de contato.

Também temos a comunidade Dados Livres no Telegram. Entre para a nossa comunidade e compartilhe no grupo as suas contribuições, dúvidas ou sugestões ao projeto, para que mais pessoas se interessem em participar do grupo.


Tópicos de contribuição


1. Cadastre fontes e aplicações que usam dados abertos


Você pode contribuir com o projeto ajudando no cadastro de fontes de dados abertos ou aplicações cívicas. Primeiro, é preciso realizar um login na plataforma ou caso ainda não seja um usuário cadastrado, é necessário realizar um cadastro na plataforma. Depois, preencher o formulário de cadastro da fonte ou aplicação que deseja cadastrar.

As imagens abaixo mostram os formulários de cadastro da fonte e aplicação:





Na plataforma temos uma página chamada ranking de colaboração para rankear os usuários a partir da quantidade de cadastros das fontes de dados abertos e aplicações cívicas, para estimular a colaboração dos usuários com essas fontes ou aplicações.


2. Contribua com o código-fonte


O código-fonte do projeto está disponível na plataforma do GitLab e licenciado sob Licença GNU GPLv3.

O sistema usa a linguagem de programação Python com a Microframework web Flask. Também, é utilizado as tecnologias web HTML5, CSS3, JavaScript e o framework Bootstrap.

Sub-tópicos de contribuição com o código-fonte


2.1 Melhore o design da plataforma


Melhore a experiência e as interações dos usuários com o sistema, aplique seus conhecimentos de design UX e UI, sugira uma paleta de cores ou fontes de texto, melhore a logo da plataforma e muito mais.

Clique aqui para discutir sobre o tópico de design


2.2 Adicione outros idiomas ao projeto ou faça correções nas traduções


Contribua adicionando textos em inglês no dadoslivres.org ou no repositório do projeto. Ajude a corrigir textos, adicione traduções nas fontes e aplicações, contribua para que Dados Livres se torne mais vísivel a outras pessoas.

Clique aqui para discutir sobre o tópico de idioma e traduções


2.3 Aplique testes de software e relate por bugs no sistema


Ajude aplicando testes de software utilizando os conceitos de TDD, relate e solucione possíveis bugs. Contribua para melhorar a qualidade da aplicação.

Clique aqui para discutir sobre o tópico de testes


2.4 Aplique melhorias de segurança


Reforce a segurança da plataforma encontrando possíveis falhas de segurança no sistema.

Clique aqui para discutir sobre o tópico de segurança


2.5 Melhore a documentação


Ajude melhorando o texto da documentação do Dados Livres.

Clique aqui para discutir sobre o tópico de documentação


2.6 Ajude no desenvolvimento da API


Ajude no desenvolvimento de uma API Web para o Dados Livres.

Clique aqui para discutir sobre o tópico de API
